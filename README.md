# iny-build

**그린 화면을 실제로 짓고 올리고, 받아봐서 확인하는 Claude Code 스킬입니다.**

04 에서 **화면을 그리셨습니다.** 요소마다 만드는 순서까지 적혀 있고요.

**그런데 그건 아직 파일입니다. 이 컴퓨터 밖에서는 아무도 못 봅니다.**

**여기서는 그걸 실제로 짓고 인터넷에 올립니다.**
그리고 **올린 주소를 스킬이 받아봐서 진짜 되는지 확인합니다.**

에셋엔진 워크플로우의 **05단계**입니다. `v1.0`

---

## ★ 받아보는 게 이 스킬의 심장입니다

**앞 단계들은 파일을 만들면 끝이었습니다. 여기는 아닙니다.**

| | |
|---|---|
| 01~04 | **파일을 만들면 끝.** 열어보면 맞는지 보입니다 |
| **05** | **짓고, 올리고, 그게 밖에서 어떻게 보이는지가 결과입니다** |

**파일에는 다 맞게 적혀 있는데 올리고 나면 막혀 있는 일이 흔합니다.**

| 조용히 막히는 자리 | |
|---|---|
| 올린 곳의 **AI 봇 차단 스위치** | 켜면 주요 AI 로봇이 다 막힙니다. **「보안」처럼 보여서 켜기 쉽습니다** |
| **미리보기 주소를 올린 주소로 착각** | 미리보기는 검색이 안 가져갑니다 |

**눈으로는 멀쩡해 보입니다.** 그래서 받아봐야 압니다.

```
  ○  검색 금지 머리글 없음
  ○  자바스크립트 없이 글이 보입니다
  ✕  대표 주소가 없습니다
  ✕  나눌 때 뜨는 그림이 상대 주소입니다  ← 절대 주소여야 뜹니다
  ○  GPTBot 들어와집니다
```

**컴퓨터에 이미 있는 것만 씁니다.** 검사에는 아무것도 안 깝니다.

## ★ 검사표가 세 번 쌓입니다

**05 가 지은 걸 05 가 잽니다. 그건 자기 채점입니다.**

그래서 검사표를 **한 번 재고 끝나는 문서로 안 만듭니다.**

| 누가 | 언제 | 무슨 자로 | 무엇을 잡나 |
|---|---|---|---|
| **05** | 짓고 올린 직후 | 받아보기 | 짓다가 빠뜨린 것 |
| **06** | 첫 글을 쓰기 전에 | **같은 받아보기** | **05 가 잘못 적었거나 올린 뒤 바뀐 것** |
| **07** | 감사할 때 | **감사 도구** | **우리 자에 없는 항목** |

```
| 항목 | 05 | 06 | 07 |
```

**세 칸이 어긋나면 그 자리가 볼 자리입니다.**

## 앞 화면을 먼저 세웁니다

**한 번에 다 지으면 중간에 끊겼을 때 아무것도 안 남습니다.**

```
앞 화면을 짓는다 → 올린다 → 받아서 잰다 → 고친다 → 그다음 관리 화면
```

| | |
|---|---|
| 앞 화면까지만 돼도 | **사이트가 서 있습니다.** 사람이 볼 수 있습니다 |
| 관리 화면에서 막혀도 | **되돌아갈 자리가 있습니다** |
| 일찍 재면 | **막힌 자리를 먼저 잡습니다.** 다 짓고 나서 잡으면 다시 짓습니다 |

## 여기서는 뭔가를 깝니다

**앞 단계들과 다릅니다.**

| | |
|---|---|
| 01~04 | **아무것도 안 깔았습니다.** 문서만 만들었으니까요 |
| **05** | **짓는 도구가 필요합니다.** 안 깔면 사이트가 안 섭니다 |

**「아무것도 안 깝니다」라고 말하지 않습니다. 거짓말이 되니까요.**

**대신 셋을 문서에 적습니다.**

| | |
|---|---|
| 1 | **무엇을 왜 깔았나** |
| 2 | **어디에 깔렸나** (작업 폴더 안인지 컴퓨터 전체인지) |
| 3 | ★ **지우려면 어떻게 하나** |

**3번이 없으면 그 문서는 미완성입니다.** 나중에 「이게 뭐였지」 하고 못 지우십니다.

### 필요 없는 건 안 깝니다

**04 산출물을 열어보면 바깥 서비스와 주고받을 게 거의 없습니다.**
개인 사이트는 대개 **읽기만 하는 사이트**입니다.

그러면 이게 전부 필요 없습니다.

```
열쇠를 넣는 자리 · 실패를 다루는 자리 · 로그인 · 데이터베이스 · 상태를 들고 다니는 장치
```

**이걸 모르고 시작하면 없는 복잡함을 먼저 준비하고, 그러면 개인 사이트가 안 섭니다.**
**세어보고 시작합니다.**

## 04 가 정한 걸 다시 정하지 않습니다

| | 누가 |
|---|---|
| 어느 화면에 무슨 표시가 붙나 | **04** |
| 그 값이 어느 칸에서 오나 | **04** |
| **실제로 붙이고 값을 채우기** | **05** |

### 색은 근거 문서에서만 가져옵니다

**화면설계서 파일에는 색이 두 종류로 섞여 있습니다.**

| | |
|---|---|
| 미리보기 안의 색 | **사이트 색입니다** |
| 문서를 꾸미는 색 | **사이트 색이 아닙니다.** 화면설계서라는 문서 자체의 스타일입니다 |

**통째로 읽고 뽑으면 둘이 섞입니다.** 그래서 색과 글꼴은 **근거 문서에서만** 가져옵니다.

## 관리 화면은 동작까지 만들고, 막습니다

**04 가 뼈대를 그려 뒀고 05 가 동작까지 만듭니다.**

| | 05 |
|---|---|
| 화면이 보이나 · 들어가는 자리 막기 | **만듭니다** |
| 글 목록 · 상태 바꾸기 · 켜고 끄기 · 갈래 편집 | **만듭니다** |
| **글마다 제목 · 요약 · 답하는 질문 · 그림글 넣는 칸** | **만듭니다** |
| 지표 화면의 실제 숫자 | 08 |
| **그 칸을 실제로 채우는 것** | **06** |

### 그림글 칸을 반드시 만듭니다

**제목과 요약은 규칙만 있으면 자동으로 채워집니다. 그림글은 아닙니다.**
**그림마다 사람이 봐야 합니다.**

> **칸이 없으면 06 이 그림글을 넣을 자리가 없습니다.
> 그러면 그림이 안 보이는 분에게 아무것도 안 남습니다.**

### 셋을 다 막습니다

```
기계가 읽는 표시를 안 붙임  ·  로봇을 안 들임  ·  사이트맵에 안 넣음
```

**하나라도 빠지면 관리 화면이 검색에 뜹니다.**
**막았다고 믿지 않고 받아봐서 확인합니다.**

## 사이트 주소는 안 사셔도 됩니다

**02 에서 이름을 정하셨죠. 사는 건 여기서 하셔도 되고 안 하셔도 됩니다.**

### 「공짜 주소는 검색에 안 나온다」고 말하지 않습니다

**널리 퍼진 말인데 사실이 아닙니다.** 제대로 올린 것이면 **공짜 주소도 검색에 나옵니다.**
막히는 건 **미리보기처럼 「올린 것으로 지정 안 된」 주소**입니다.

**그래도 사시는 게 좋은 이유가 셋 있습니다.**

| | |
|---|---|
| 1 | **나중에 옮기면 그동안 걸린 링크가 다 죽습니다** |
| 2 | 계정을 묶는 중심이 남의 주소 아래면 약합니다 |
| 3 | 프로젝트 이름을 바꾸면 주소가 바뀝니다 |

**겁을 드려서 사게 하지 않습니다.**

```
사이트 짓기
```

안내문이 먼저 나오고, 그다음 질문 네 개가 이어집니다.

| | | |
|---|---|---|
| 1 | 04 에서 그린 화면을 읽습니다 | 기다리시면 됩니다 |
| 2 | **주소를 어떻게 만들지** 고르기 | 질문 1개 |
| 3 | **어디에 올릴지** 고르기 | 질문 1개 |
| 4 | **앞 화면을 짓고 올립니다** | 기다리시면 됩니다 |
| 5 | **받아봐서 잰 결과를 보여드림** | |

| 7 | **사이트 주소를 지금 살지** 고르기 | 질문 1개 |

중간에 멈추셔도 되고, 모르는 건 안 정하고 넘어가셔도 됩니다.
**완주해야만 사이트가 서는 게 아닙니다.** 앞 화면까지만 돼도 섭니다.

| | |
|---|---|

| `plan.md` | 지금 어디까지 됐고 다음에 뭘 하나 |

## 알아둘 것

### 개수를 미리 약속하지 않습니다

화면 몇 장 · 파일 몇 개 · 며칠 걸린다를 미리 말하지 않습니다.
**조건 넷을 걸고 다 짓고 나서 말씀드립니다.**

| | |
|---|---|
| 1 | 04 화면 종류가 전부 실제로 열린다 |
| 2 | **받아본 결과에 ✕ 가 0개다.** 못 고친 것은 왜 못 고치는지 적혀 있다 |
| 3 | 관리 화면이 셋 다 막혀 있다 |
| 4 | **틀마다 실물 하나로 열어봤다** |

### 「이 틀로 실물 하나를 만들어봤나」

04 는 「글 한 편」 화면을 한 장으로 그렸고, 그 틀을 글 여러 편이 씁니다.
**그런데 지금 글이 0편이면 넣어볼 게 없습니다.**

그냥 넘어가면 **틀이 맞는지 모르는 채로 통과하고, 06 이 첫 글을 쓸 때 그제야 터집니다.**

**하나만 만들어 열어보고 지웁니다. 지웠다고 적습니다.**

### 자료에 없는 것은 지어내지 않습니다

04 가 **「재료에 없음」**이라고 적어둔 칸은 **비웁니다.**
받아보다 **못 잰 것은 「안 잼」과 왜 못 쟀는지**를 적습니다. 짐작해서 ○ 를 안 적습니다.

### 연락처는 넣기 전에 여쭤봅니다

04 에서 연락 칸을 두셨으면 **그 값이 코드에 들어가고, 올리면 그대로 공개됩니다.**
**넣기 전에 한 번 짚어 드립니다.** 04 가 관리 화면에서 끄는 자리도 같이 그려 뒀습니다.

### 열쇠를 코드에 안 박습니다

올리면 그대로 공개되고 되돌리기 어렵습니다.
**밖에 안 보이는 자리에 두고, 그 자리가 어디인지만 문서에 적습니다.**

### 스킬이 알아서 커밋하지 않습니다

뭐가 들어갔는지 모른 채 이력이 쌓이는 걸 막습니다.

### 04 산출물을 안 고칩니다

화면을 더하거나 요소를 바꾸지 않습니다. **04 가 그린 것을 그대로 짓습니다.**
