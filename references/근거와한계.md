# 근거와 한계 · 05 가 무엇을 믿고 무엇을 안 믿나

**05 는 짓는 단계다. 재는 것은 07 이다.**
여기 있는 것은 **짓기 전에 알아야 부정된 처방을 안 짓게 되는 것**들이다.

**이 파일이 05 의 뼈대다.** 감사 도구가 시키는 것 중 **데이터로 부정된 것**이 여럿이다.
05 가 그걸 모르면 도구가 시키는 대로 하고 만다.

---

## 0. ★ 넣을 수 있는 건 다 넣는다. 대신 등급을 나눈다

**05 가 남들과 다른 점은 「덜 넣는 것」이 아니다. 「무엇이 근거 있는지 아는 것」이다.**

| | 무엇을 아나 |
|---|---|
| 공개 감사 도구 | **일반적인 정답.** 「대개 이렇게 하면 좋다」 |
| **05** | **그중 무엇이 데이터로 부정됐는지.** 1장 |

**07 이 나중에 도구를 돌린다. 05 는 그 도구가 시킬 것을 미리 알고 짓는다.**
**07 에서 되돌아오는 횟수를 줄이는 게 05 가 이 문서를 읽는 이유다.**

### 근거가 없다고 빼지 않는다

**빼면 세 가지를 잃는다.**

| | |
|---|---|
| 1 | **06 에서 감사 도구가 X 를 뱉고 그때 되돌아온다** |
| 2 | ★ **08 이 잴 수 없다.** 넣어야 「진짜 효과가 없나」를 이 사이트에서 확인한다 |
| 3 | ★ **기록이 안 남는다.** 남들은 「넣으세요」라고만 하는데, 넣고 재본 숫자는 그 자체가 콘텐츠다 |

**2번이 특히 크다.** 반증 1번은 확인법을 이렇게 적어놨다.

> 파일을 만들었다면 인용 변화 말고 **서버 로그에서 요청 수를 30일간 세라. 0이면 끝**

**안 넣으면 영영 모른다.**

### 등급 넷

| 등급 | 넣나 | 무엇 |
|---|---|---|
| **근거 있음** | **넣는다** | 검색이 실제로 쓰는 것 |
| **근거 없음 · 값이 안 든다** | **넣는다.** 「근거 없음」 표시를 붙이고 **08 이 잰다** | 반증됐거나 잰 연구가 없는 것 |
| **넣으면 거짓말** | **안 넣는다** | 없는 것을 있다고 적게 되는 것 |
| **넣으면 손해** | **안 한다** | 얻는 것 없이 잃기만 하는 것 |

**안 넣는 건 아래 둘뿐이고 이유가 「효과 없음」이 아니다.**

| 안 넣는 것 | 왜 |
|---|---|
| **회사 표시 · 상품 표시 · 가게 정보** | **개인 사이트에 회사도 상품도 가게도 없다.** 넣으면 **없는 걸 있다고 적는 것**이다 |
| **AI 봇 막기** | **X12.** 막아도 인용은 70.6% 그대로 일어나고 **방문만 잃는다** |

> **효과가 없다는 것과 거짓이라는 것은 다르다. 효과가 없는 건 넣고 잰다. 거짓은 안 넣는다.**

### 값이 드는 것은 따로 본다

「값이 안 든다」의 조건은 **자동으로 만들어질 때**다.
**사람이 손으로 관리해야 하는 것은 낡는다.** 그건 값이 드는 것이다.

| | |
|---|---|
| 자동으로 만들어진다 | **넣는다.** 관리 비용이 0 |
| 사람이 손으로 채워야 한다 | **05 가 「어디에서 채우나」까지 규칙으로 쓴다.** 채울 자리가 없으면 안 넣는다 |

각 줄의 「범위」 칸을 반드시 같이 읽는다. **반증에도 적용 범위가 있다.**

## 2. ★ X9 의 처방이 04·05 가 한 것과 정확히 같다

반증 9번에 **무엇을 대신 하라는지**가 적혀 있다.

> **형식적 질문 답변 블록을 제거하고, 그 질문들을 본문 작은 제목으로 승격해
> 3문단 이상 실질 답변으로 만든다**

**04 가 화면에 질문 자리를 잡았고 05 가 규칙을 쓴다.** 그 규칙이 이것이다.

| | |
|---|---|
| **제거** | 질문 답변 표시(기계용 블록)를 안 붙인다 |
| **승격** | **질문을 본문 작은 제목으로 쓴다.** 한 줄 걸고 마는 게 아니다 |
| **실질 답변** | 그 아래 답이 **본문의 실제 내용**이어야 한다 |

**07 이 글을 쓸 때 이 규칙을 받는다.** 05 는 규칙까지다.

**한편 질문형 제목 자체는 값이 크다.** 질문형 제목 인용 78.4% · 질문형 검색에서 AI 요약 발동 64.7%.
**깎인 건 속이 빈 포맷이지 질문이 아니다.**

## 3. ★ X12 가 로봇 규칙을 뒤집는다

「학습에만 쓰는 봇은 막자」가 상식처럼 돌아다닌다. **데이터가 반대다.**

| | |
|---|---|
| 막으면 | **인용은 70.6%가 그대로 일어난다.** 못 막는다 |
| 그런데 | **그 봇을 통해 올 수 있었던 방문은 잃는다** |
| 그래서 | **막는 건 잃기만 하는 거래다** |

> **완전히 막으려면 「검색에 싣지 마라」 표시가 필요한데,
> 그 표시를 읽히려면 로봇을 들여야 한다.** 막으면 그 표시조차 못 읽는다.

**05 는 이걸 클릭 보기 설명에 그대로 적는다.** 고르는 사람이 이 사실을 알고 골라야 한다.

## 6. 그럼 기계가 읽는 표시를 왜 넣나

**X2 가 반증인데도 넣는다.** 이유를 바꾸는 것이지 빼는 게 아니다.

| | |
|---|---|
| 반증 범위 | **이미 100회 이상 인용된 페이지가 대상이다** |
| 이제 시작하는 사이트 | **인용 0회. 범위 밖이다** |
| 그렇다고 근거가 있나 | **없다.** 스키마가 LLM 인용에 미치는 영향을 측정한 학술 연구가 하나도 없다 |

**늘어난다는 근거도 없고 안 늘어난다는 근거도 이제 시작하는 사이트엔 안 맞는다.**
남는 건 하나다. **확실히 하는 일이 무엇인지로 이유를 바꾼다.**

| 확실히 하는 일 | |
|---|---|
| 1 | **흩어진 계정이 같은 사람임을 알린다** |
| 2 | **검색 결과에 날짜와 저자가 붙는다** |

**반증 자신도 이렇게 적어놨다.** 「리치 리절트 목적이면 유지. **AI 인용 목적으로 우선순위 상단에 올리지 말 것**」

## 7. 감사 도구가 시키는 것과 우리 판정

**06 이 감사 도구를 돌릴 것이다. 도구는 반증을 모른다.**
`기술규칙.md` 맨 뒤에 이 표를 넣어 06 이 도구 결과에 끌려가는 것을 막는다.

| 도구가 시키는 것 | 우리 | 등급 · 왜 |
|---|---|---|
| 사이트맵 · 대표 주소 · 제목 · 요약 | **한다** | **근거 있음.** 검색이 실제로 쓴다 |
| 그림글 · 자막 | **한다** | **근거 있음.** 못 보는 사람에게 필요하다 |
| 고친 날짜 | **한다** | **근거 있음.** 검색 결과에 날짜가 붙는다 |
| 로봇을 열어라 | **한다** | **근거 있음** |
| 기계가 읽는 표시를 채워라 | **한다** | **근거 없음.** **X2.** 넣되 **이유가 다르고**, 08 이 잰다 |
| `llms.txt` 를 만들어라 | **만든다** | **근거 없음.** **X1.** 자동으로 만들고 **08 이 서버 로그로 잰다** |
| 질문 답변 표시를 넣어라 | **넣는다** | **근거 없음.** **X9.** 다만 **질문이 본문에 글자로 있을 때만.** 아래 |
| 아직 표준이 아닌 파일들을 만들어라 | **만든다** | **근거 없음.** 자동으로 만들어지면 값이 안 든다 |
| 첫 100자에 답과 숫자를 넣어라 | **07 규칙으로 넘긴다** | **X8 이 걸린다.** 확정 아님으로 표시 |
| **회사 표시를 넣어라** | **안 넣는다** | **거짓말.** 개인 사이트에 회사가 없다 |
| **상품 · 가격 · 가게 정보를 넣어라** | **안 넣는다** | **거짓말.** 파는 물건도 가게도 없다 |
| **AI 봇을 막아라** | **안 막는다** | **손해.** **X12.** 잃기만 한다 |

### 질문 답변 표시를 넣는 조건

**04 가 질문을 본문 글자로 그려 뒀으면 넣을 수 있다.**

| | |
|---|---|
| 조건 | **진짜 질문이고 그 아래 진짜 답이 있을 때만.** 빈 껍데기에 붙이면 오용이다 |
| 알아둘 것 | **개인 사이트에는 리치 리절트가 안 나온다.** 검색 결과 모양은 안 바뀐다 |
| 그래도 넣는 이유 | **08 이 잴 수 있게. 그리고 06 에서 감사 도구가 X 를 안 뱉게** |
| 화면에 없는 질문 | **안 넣는다.** 「보이는 것만」 규칙이 여기서도 이긴다 |

> **어긋나면 05 규칙이 이긴다.** 도구가 우리 사이트를 모르기 때문이다.
> **다만 어긋나는 건 위 셋뿐이다. 나머지는 다 넣는다.**
