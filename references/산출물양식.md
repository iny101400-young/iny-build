# 산출물 양식 · 05 가 무엇을 어떤 모양으로 쓰나

**여기 나오는 값은 전부 지어낸 것이다.** 앞사람 산출물에서 가져온 것이 하나도 없다.
**모양만 보고 값은 그 사람 것으로 채운다.**

---

## 0. 셋 다 md 로 낸다

**05 산출물은 읽는 쪽이 사람과 다음 스킬이다.** 그림이 없다.
**사이트 자체가 그림이다.** 문서는 그걸 설명한다.

## 4. 공통 규칙

| | |
|---|---|
| **절대경로** | 산출물에 안 적는다. 사용자 이름이 박혀 있다 |
| **열쇠** | **산출물에 안 적는다.** 어디에 두었는지만 |
| **연락처 값** | 사이트에는 들어가되 **문서에는 안 적는다** |
| **대시와 불릿** | 대시(—)와 하이픈 불릿을 안 쓴다. 표나 번호로 쓴다 |
| **「나중에」 · 「필요하면」 · 「사용자가 직접」** | 안 쓴다. **왜 못 했는지**를 쓴다 |
| **빈칸** | 안 남긴다. **「재료에 없음」**과 빈칸은 다르다 |
| **짐작** | **받아본 것만 적는다.** 못 쟀으면 「안 잼」과 왜 |
| **개수** | 미리 안 박는다. 다 짓고 나서 적는다 |
| **어려운 말** | 처음 나오는 자리에서 한 번 풀어 준다 |
