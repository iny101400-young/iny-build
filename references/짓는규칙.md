# 짓는 규칙 · 05 가 무엇을 어떻게 짓나

**이 파일은 판단 기준이다.** 코드가 아니다.
05 는 이걸 읽고 그 사람의 04 산출물에 맞춰 짓는다.

**여기 나오는 예시는 전부 지어낸 것이다.** 앞사람 산출물에서 가져온 것이 하나도 없다.

---

## 0. ★ 짓기 전에 세 가지를 센다

**세어보면 안 만들어도 되는 것이 드러난다.** 화면에는 안 낸다.

| 세는 것 | 알게 되는 것 |
|---|---|
| `API` 가 「없음」인 개수 | **바깥 서비스를 다룰 자리가 있나** |
| `Logic` 이 「없음」인 개수 | **동작을 만들 자리가 몇 개인가** |
| 화면 종류 개수 | 얼마나 지어야 하나 |

### 「없음」이 대부분이면 그 층을 아예 안 만든다

**개인 사이트는 `API` 가 거의 다 「없음」이다.** 그러면 아래가 전부 필요 없다.

| 안 만드는 것 | 왜 |
|---|---|
| 열쇠를 넣는 자리 | 주고받을 바깥 서비스가 없다 |
| 실패를 다루는 자리 | 실패할 통신이 없다 |
| 로그인 · 회원 · 데이터베이스 | 앞 화면에는 안 쓴다 |
| 상태를 들고 다니는 장치 | 읽기만 하는 사이트다 |

> **이걸 모르고 시작하면 없는 복잡함을 먼저 준비한다.
> 그러면 개인 사이트가 안 선다.**

**「없음」이 아닌 자리만 만든다.** 대개 연락 칸 하나다.

## 1. 주소

### 짓기 전에 정한다

**나중에 바꾸면 그동안 걸린 링크가 다 죽는다.**

| | |
|---|---|
| 갈래를 주소에 넣을지 | **클릭 ① 로 받는다.** 03 이 후보 둘을 냈다 |
| 한글을 주소에 둘지 | **클릭 ① 에 같이 받는다** |
| 글 자리의 이름 | 04 가 화면 옆에 적어둔 것을 따른다 |

### 묻지 않고 정하는 것

| | 왜 |
|---|---|
| **소문자로 고정** | 02 표기와 같은 이유다. 섞이면 같은 사람으로 안 묶인다 |
| **날짜를 안 넣는다** | 글이 낡아 보이고, 글을 고치면 주소가 죽는다 |
| **낱말은 하이픈으로 잇는다** | 밑줄은 검색이 한 낱말로 읽는다 |
| **주소 끝 슬래시를 한쪽으로 고정** | 붙인 것과 안 붙인 것이 다른 주소가 된다 |
| **끝에 확장자를 안 붙인다** | 나중에 짓는 방식을 바꾸면 주소가 다 죽는다 |

### 대표 주소를 모든 공개 화면에 붙인다

**없으면 검색이 어느 쪽을 실을지 스스로 고른다.**

| 같은 글이 여러 주소로 열리는 자리 | |
|---|---|
| 슬래시가 있고 없고 | `/글/이름` 과 `/글/이름/` ← 지어낸 예시입니다 |
| 검색어가 주소에 붙을 때 | `/글?어디서=메일` ← 지어낸 예시입니다 |
| 목록의 두 번째 장 | **각 장이 자기 자신을 가리킨다.** 첫 장을 대표로 안 한다 |

### 주소가 바뀌면

**옛 주소가 새 주소를 가리키게 한다.** 그냥 없애면 그동안 걸린 링크가 다 죽는다.

## 2. 화면을 짓는 차례

### 되풀이 쓰는 값을 먼저 박는다

**색 · 글꼴 · 간격 · 모서리를 한 자리에 모아 두고 화면마다 그걸 가져다 쓴다.**
화면마다 값을 적어 넣으면 나중에 하나 고칠 때 전부 뒤져야 한다.

> ★ **값은 `근거.html` 에서만 가져온다.**
> 화면설계서 파일에는 **문서 자체를 꾸미는 색**이 섞여 있다. 그건 사이트 색이 아니다.

**근거에만 있고 미리보기에 안 나온 색이 있다.** 상태 색과 경고 색이 대개 그렇다.
**미리보기에 안 보인다고 빼지 않는다.**

### 그다음 순서

| | 무엇 | 왜 이 차례인가 |
|---|---|---|
| 1 | **모든 화면에 들어가는 머리와 발** | 화면마다 다시 안 만든다 |
| 2 | **내용이 이미 있는 화면** | **일찍 올려서 일찍 잰다** |
| 3 | **글이 0편일 때 화면** | 04 가 그려 놨다. 지금이 그 상태다 |
| 4 | **없는 주소 화면** | 안 만들면 기본 화면이 나온다 |

**2번이 중요하다.** 볼 게 있는 화면부터 지어야 올려서 받아볼 수 있다.

### 04 가 캐둔 것을 지금 채운다

**04 가 「만든 것」을 자료에서 캐서 표로 채워 놨다.** 글과 달리 **지금 내용이 있다.**

| | |
|---|---|
| 채운다 | 이름 · 무엇 · 언제 · 지금 볼 수 있나 |
| **「재료에 없음」이라고 적힌 칸** | **비운다.** 지어내지 않는다 |
| 그림 | 04 가 자리만 잡았으면 **자리만 짓는다** |

**안 채우면 빈 사이트가 된다.** 글이 0편인데 만든 것까지 비면 볼 게 없다.

### 요소 하나를 다섯 층 그대로 옮긴다

| 층 | 짓는 자리 |
|---|---|
| `UI` | 보이는 모양 |
| `Logic` | 누르면 일어나는 일. **「없음」이면 안 만든다** |
| `Data` | 값이 어디서 오나 |
| `API` | 바깥과 잇는 통로. **「없음」이면 안 만든다** |
| `Deploy` | 언제 만들어지나 |

**04 가 상태 다섯을 적어 놨다.** 누를 수 있는 것마다 그대로 만든다.
**「초점이 갔을 때」를 빼먹지 않는다.** 키보드로 다니는 사람이 쓴다.

### ★ 껐다 켤 수 있는 값을 제목으로 안 쓴다

**04 요소 중 「켜고 끄기」가 붙은 것을 먼저 추린다.**
그중 하나라도 제목 자리에 있으면 **제목 자리를 따로 뗀다.**

1회차에 컨택 화면의 큰제목이 메일 주소 그 자체였다.
사용자가 메일을 끄자 그 화면에 큰제목이 하나도 없어졌다.

| 뼈대 · 항상 있다 | 살 · 껐다 켤 수 있다 |
|---|---|
| 제목 · 갈래 이름 · 메뉴 | 메일 · 실명 · 사진 · 계정 |

**04 산출물은 안 고친다.** 05 에서 제목 자리를 만들고 `지은것.md` 의
「04 로 넘길 것」에 적는다.

### 화면이 좁을 때

**04 가 화면마다 「폰에서 볼 때」를 적어 놨다.** 그대로 만든다.
**적혀 있는데 안 만들면 04 산출물을 버리는 것이다.**

## 3. 기계가 읽는 표시 · 파일 셋

### 표시는 04 가 정한 대로 붙인다

**05 는 붙이는 쪽이다. 종류를 다시 정하지 않는다.**

| | |
|---|---|
| **본문에 글자로 안 보이는 값을 안 넣는다** | 화면에 그 글자가 없으면 넣지 않는다 |
| **계정을 묶는 자리는 한 번만** | 여러 곳에 적으면 고칠 때 어긋난다 |
| **관리 화면에는 안 붙인다** | 4장 |
| 04 에 안 적힌 화면이 있으면 | **05 가 정하고 「04 에 없어서 정했다」고 적는다** |

### 로봇 파일

| | |
|---|---|
| **막지 않는다** | 막아도 인용은 70.6% 그대로 일어나고 방문만 잃는다 |
| **이름 목록을 이 파일에 안 박는다** | **계속 바뀐다.** 지을 때 지금 도는 이름을 확인한다 |
| **관리 화면은 막는다** | 4장 |
| 맨 아래 | **사이트맵이 어디 있는지 적는다** |

> ★ **로봇 파일에 관리 화면 주소를 적는 것 자체가 그 주소를 알려주는 일이다.**
> **화면 자체에도 「싣지 마라」 표시를 같이 단다.**

### 사이트맵

| | |
|---|---|
| 넣는 것 | **공개 주소만** |
| 안 넣는 것 | 관리 화면 · 없는 주소 화면 · **아직 안 쓴 글의 주소** |
| 시각 | **손으로 안 적는다.** 파일에서 자동으로 온다 |
| 우선순위 숫자 | **안 적는다.** 검색이 안 본 지 오래됐다 |

**없는 글 주소를 미리 넣으면 로봇이 와서 빈 화면을 보고 간다.**

### `llms.txt`

| | |
|---|---|
| 무엇 | AI 에게 사이트에 뭐가 있는지 글로 알리는 파일 |
| **등급** | **근거 없음.** 이 파일의 대부분이 한 달간 요청 0건이었다는 조사가 있다 |
| **그래도 넣나** | **넣는다.** 자동으로 만들어지면 값이 안 든다 |

| 산출물에 | **「근거 없음 · 서버 기록으로 잰다」**를 적는다 |

### 그 밖에 붙이는 것

| 탭에 뜨는 작은 그림 | 04 가 정한 색에서 |
| **고친 날짜** | 검색 결과에 날짜가 붙는 근거. **파일에서 자동으로** |

## 4. 관리 화면 · 막는 게 절반이다

### 셋을 다 막는다

| | |
|---|---|
| 1 | **기계가 읽는 표시를 안 붙인다** |
| 2 | **로봇을 안 들인다** |
| 3 | **사이트맵에 안 넣는다** |

**하나라도 빠지면 관리 화면이 검색에 뜬다.**

### 들어가는 자리를 막는다

**막는 방법은 지은 방식에 따라 다르다.** 다만 규칙은 같다.

| | |
|---|---|
| **열쇠를 코드에 안 박는다** | 올리면 그대로 공개된다. **되돌리기 어렵다** |
| **밖에 안 보이는 자리에 둔다** | 그 자리가 어디인지 `지은것.md` 에 적는다 |
| **어떻게 들어가는지 알려준다** | 안 알려주면 못 들어간다 |

### 05 가 짓는 것과 안 짓는 것

| | 05 |
|---|---|
| 화면이 보이나 | **짓는다** |
| 글 목록 · 상태 바꾸기 · 켜고 끄기 | **짓는다** |
| 갈래 편집 | **짓는다** |
| **글마다 제목 · 요약 · 답하는 질문 · 그림글 넣는 칸** | **짓는다** |
| 지표 화면의 실제 숫자 | **안 짓는다.** 08 |
| **그 칸을 실제로 채우는 것** | **안 한다.** 06 |

### ★ 그림글 칸을 반드시 만든다

**제목과 요약은 규칙만 있으면 자동으로 채워진다. 그림글은 아니다.**
**그림마다 사람이 봐야 한다.**

> **칸이 없으면 06 이 그림글을 넣을 자리가 없다.
> 그러면 그림이 안 보이는 사람에게 아무것도 안 남는다.**

**그림글 쓰는 규칙도 그 칸 옆에 적어 둔다.**

| | |
|---|---|
| 「이미지」 · 「사진」이라고 안 쓴다 | 읽어주는 기계가 두 번 읽는다 |
| 화면 캡처면 | **그 화면이 무슨 화면인지** 적는다 |
| 꾸미려고 넣은 그림은 | **빈 글로 둔다.** 기계가 건너뛴다 |
| 글자가 든 그림은 | 그 글자를 적는다 |

### ★ 사진을 올리는 칸도 같이 만든다

**그림글 칸만 있고 사진 올리는 칸이 없으면 06 이 그림글만 적고 그림은 못 넣는다.**

| | |
|---|---|
| 고르면 바로 올린다 | 저장을 눌러야 올라가게 하면, 저장 안 하고 닫았을 때 사진만 남아 떠돈다 |
| 받는 형식을 못 박는다 | 못 박으면 안 열리는 사진이 섞인다 |
| 크기 한도를 적는다 | 담을 데 한도가 있다. 한도와 함께 화면에 적는다 |
| **이름을 새로 지어서 올린다** | 아래를 본다 |

## 5. 담을 데를 붙인다

**04 의 `API` 가 전부 「없음」이어도 담을 데는 따로다.**
글과 사진은 사용자가 바꾸는 값이라 어딘가에 담겨야 한다. STEP 4 에서 정한 곳에 붙인다.

### ★ 파일 이름을 영문으로 새로 지어서 올린다

**사람이 고른 파일 이름을 그대로 쓰지 않는다.**

| 왜 | |
|---|---|
| 1 | **한글 이름을 안 받는 곳이 있다.** 1회차에 `InvalidKey` 로 막혔다 |
| 2 | 같은 이름이면 앞엣것이 사라진다 |

**날짜와 안 겹치는 글자를 붙여 짓는다.** 확장자는 받은 형식에서 가져온다.

### ★ 읽을 때 주소를 매번 다르게 한다

**담을 데도 응답을 갖고 있다가 옛것을 내준다. 지역마다 따로 갖고 있다.**

1회차에서 「새것 달라」는 머리글만 붙였다가 막혔다.
**내 컴퓨터에서는 새 값이 오고 올린 곳에서는 옛 값이 왔다. 그동안 오류가 하나도 안 났다.**

| 어디 | 무엇 |
|---|---|
| 읽을 때 | 주소 뒤에 매번 다른 글자를 붙인다. 주소가 달라지면 앞단이 새로 가져올 수밖에 없다 |
| 담을 때 | 「갖고 있지 마라」를 담는 순간부터 박아 둔다 |
| **사진은 예외** | 이름이 매번 달라 겹칠 일이 없다. **오래 갖고 있는 게 빠르다** |

### ★ 못 읽으면 떨어질 데를 두되 소리를 낸다

| | |
|---|---|
| 떨어질 데 | 지을 때 받아둔 파일. **담을 데가 잠들어도 사이트는 선다** |
| **소리** | **무엇을 왜 못 읽었는지 남긴다.** 조용히 넘어가면 화면이 멀쩡해서 아무도 모른다 |

### 잠들지 않게 하는 자리를 같이 짓는다

**무료 요금제는 한동안 아무도 안 건드리면 잠든다.**
하루 한 번 두드리는 자리를 짓는다. **사람이 기억할 일로 남기지 않는다.**

이 자리는 로그인 뒤에 안 둔다. 부르는 게 기계라 사람 계정이 없다.
하는 일이 「살아 있나 묻기」뿐이라 남이 불러도 잃을 게 없다.

## 6. 올리기

### 「올린 것」과 「미리보기」를 가른다

**올린 곳이 주소를 여럿 준다.**

| | |
|---|---|
| 미리보기 주소 | **검색이 안 가져간다.** 그렇게 만들어져 있다 |
| **올린 주소** | **검색이 가져간다** |

> ★ **어느 쪽을 보고 있는지 확인한다. 헷갈리면 검사 결과가 통째로 틀린다.**

### 올린 곳 설정에서 막히는 자리 둘

**파일을 다 맞게 만들어도 여기서 막히면 아무것도 안 된다.**

| | |
|---|---|
| **AI 봇 차단 스위치** | 켜면 주요 AI 로봇이 다 막힌다. **「보안」처럼 보여서 켜기 쉽다** |
| **검색 금지 머리글** | 미리보기 주소에 자동으로 붙는다 |

**받아봐서 확인한다.** 설정 화면만 보고 넘어가지 않는다.

### 열쇠와 개인정보

| | |
|---|---|
| **열쇠를 코드에 안 박는다** | 올리면 그대로 공개된다 |

| **계정 주소** | 02 가 「실명이 든 주소」로 표시해 둔 게 있으면 다시 짚는다 |

## 7. 무엇으로 지을까 · 05 가 정한다

**개발을 모르는 사람에게 물으면 고를 근거가 없다.**

### 무엇을 보고 정하나

| | |
|---|---|
| 1 | **스펙과 설정에 적힌 조건.** 「미리 만들어서 보내기」가 대개 그것이다 |
| 2 | **`API` 가 「없음」인 개수.** 바깥 서비스가 없으면 가벼운 쪽 |
| 3 | **글을 파일로 두는가.** 그러면 글 파일을 그대로 읽는 방식 |
| 4 | **올릴 곳이 정해졌으면 거기서 잘 도는 것** |

### 고르는 태도

| | |
|---|---|
| **가벼운 쪽** | 개인 사이트다. 큰 틀을 쓰면 고칠 때마다 무거워진다 |
| **널리 쓰는 쪽** | 막혔을 때 찾아볼 게 있다 |
| **글이 파일로 있는 방식** | 스펙이 「변환 단계를 따로 두지 않는다」고 정했다 |

**고른 이유를 `지은것.md` 에 적는다.** 화면에는 「이걸로 짓겠습니다」 한 줄만.

### 유행을 따라 고르지 않는다

**04 가 디자인에서 걸린 자리와 같다.** 요즘 뜬다는 이유로 고르면 **고른 게 아니라 기본값**이다.
**위의 넷으로 고르고 그 넷을 적는다.**

## 9. ★ 05 가 잰 것은 자기 채점이다

**05 가 지은 걸 05 가 잰다.** 헐겁게 재도 05 안에서는 아무도 못 잡는다.

> **그래서 검사표를 세 번 쌓는 문서로 만든다.**

| 누가 | 언제 | 무슨 자로 | 무엇을 잡나 |
|---|---|---|---|
| **05** | 짓고 올린 직후 | `받아보기.sh` | 짓다가 빠뜨린 것 |
| **06** | 글을 쓰기 전에 한 번 | **같은 `받아보기.sh`** | **05 가 잘못 적었거나 올린 뒤 바뀐 것** |
| **07** | 감사할 때 | **감사 도구** | **우리 자에 없는 항목** |

**05 는 검사표 맨 위에 이 줄을 적는다.**

> 이건 05 가 자기가 지은 걸 자기가 잰 것입니다. 06 과 07 이 다시 잽니다.

**04 가 이미 같은 방식이었다.** 03 산출물이 다 자리를 가졌나를 04 가 쟀다.
**다음 단계가 앞 단계를 재는 것이 이 체인의 방식이다.**
